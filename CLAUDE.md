# Focale — notes pour Claude

Logiciel web de conception optique séquentielle (ergonomie inspirée de Quadoa, fonctions de CODE V / Zemax).
Interface et commentaires en français. Unités : mm, longueurs d'onde en µm.

## Architecture
- `src/engine.js` : moteur pur (aucune dépendance au DOM), exporté en module Node pour les tests.
  Paraxial y-nu à indices signés, tracé réel vectoriel (coniques + asphères paires, miroirs),
  pupilles paraxiales + visée réelle optionnelle, OPD/Zernike, PSF/FTM par FFT, Seidel, optimiseur DLS.
- `src/app.js` : interface (éditeur de lentilles, layout 2D/3D canvas, panneaux d'analyse, optimiseur, tolérancement…).
- `src/io.js` : import/export Zemax `.zmx` et CODE V `.seq` (module Node testable) : `decode` (UTF-16), `detect`, `parseZMX`/`toZMX`, `parseSeq`/`toSeq` ; chaque fonction renvoie aussi `warnings`. Décentrements ↔ COORDBRK, verres fictifs ↔ ___BLANK / PRV.
- `src/pdf.js` : écrivain PDF autonome (`PDF.Doc` : text/para/line/rect/poly/jpeg/build ; Helvetica, Courier, Symbol pour le grec ; WinAnsi). `src/report.js` : fenêtre « Rapport PDF » et `genReport()` (rendu hors écran en thème clair via `App.forceLight`, `drawLayout({c,w,h})`, `simSync`).
- Logo « tache d'Airy » sur tuile sombre (#0f172a, anneaux #263f64/#3c659c, cœur #60a5fa, point #f59e0b) : `src/pwa/icon.svg` (→ `icon-192/512.png` via sharp), en-tête de `shell.html`, `lensMark()` dans `report.js`.
- `src/assistant.js` : assistant en langage naturel, **module facultatif** copié en `assistant.js` (pas inclus dans `index.html`), chargé à la demande par `openAssistant()` (bouton `#asstBtn`, Ctrl+Maj+A, préférence `App.asst`). `window.ASST` : `summary()` (contexte envoyé au modèle, lentilles L1… via `lenses()`), `TOOLS` (actions : `run(args)`, `m` = modifie le système), `execute()` (une seule étape d'annulation, restauration si échec), `SYSTEM`/`SCHEMA` (JSON contraint {message, actions, question}), moteurs `askGemini` (API Gemini, clé `cfg.geminiKey`, modèle `cfg.geminiModel` = gemini-flash-latest par défaut, `GEMINI_TOOLS` depuis `OLLAMA_TOOLS`, boucle : outils de lecture `READ_ONLY` report_metrics → `metricsFull` / find_glass exécutés et renvoyés en functionResponse, contenu du modèle renvoyé tel quel (signatures), autres appels = plan ; test `/tmp/bg/tg.py` avec page.route), `askOllamaTools` (appel d'outils natif, `OLLAMA_TOOLS` depuis `PARAMS`, `ask_question` → question, `SYSTEM_TOOLS` court ; défaut) puis `askOllama` (repli JSON : flux NDJSON, `format` = schéma, `think:false` pour les Qwen3 hybrides), `simpleRule` (règles d'abord pour les demandes courtes non composées ; `fuzz` = correction des mots par `VOCAB`/`ABBR`/distance de Damerau-Levenshtein `dl`, `resolveGlass` tolère une faute sur le nom du verre ; test `/tmp/fuzz_test.py`), `fixArgs` (nombres/listes en texte) / `askWebllm` (import CDN esm.run) / `rules()` (sans IA). Test : faux serveur Ollama `/tmp/fake/ollama.py` + `/tmp/asst_test.py` (recréer au besoin).
- `src/samples.js` : systèmes d'exemple. `src/shell.html` : HTML/CSS avec marqueurs `/*__ENGINE__*/` etc.
- `index.html`, `sw.js`, `manifest.webmanifest`, `icon.svg` sont GÉNÉRÉS par `python3 build.py` (version = hash du contenu, ce qui déclenche la mise à jour des applications installées) : ne jamais les éditer à la main, toujours régénérer et commiter.

## Conventions
- Convention de signes Zemax/CODE V : épaisseurs négatives après un miroir, R > 0 centre à droite.
- OPD (`opdRef().W`) = chemin du rayon principal − chemin du rayon (> 0 = front d'onde en avance, convention CODE V/Zemax) : W040 = +SI/8 ; la PSF utilise donc la phase −2πW. Test indépendant : `/tmp/phys/check.js` (recréé au besoin) — tracé méridien et ABCD maison.
- F/# image (`aperture.type = 'FNO'`) : EPD = EFL / F# en conjugué fini comme à l'infini (Zemax « Image Space F/# »). FTM : limite de diffraction calculée sur la même pupille (`mtfOne` → DT/DS).
- Optimisation : `OPS` (opérandes, `kind` = contrainte par défaut, `op.cmp` eq/ge/le, `list` pour les épaisseurs, `p` paramètre), `opValue`, `residuals` (→ `parts`, `img2`), variables `vr/vt/vk/va4…va10` (`getVars`), `merit.wl` ('all' | 'central' | 'primary' | indice, via `wlSel`). `quickFocus(sys, {crit, wl})` (épaisseur avant l'image, solve M retiré). UI : `openOptim`, `optLive`, `runOpt`, `runGlobal` (Hammer), `quickFocusUI`, `qfMenu` (`App.qf` dans `focale.ui`).
- Verres variables : `s.vg` ; verre modèle « nd/νd » (`parseModel`, `fmtModel`, `toModel`), variables `nd`/`vd` dans `getVars` (seulement si le verre est un modèle), opérande `RGLA`, `glassNearest`/`glassPool` (écart normalisé Δnd/0,01, Δνd/1,5 ; `merit.gsub` = {cats, pref, k, passes}), `subTry` ; UI `optGlassHTML`, `runSubst`.
- Couleurs : `fields[i].col` et `wavelengths[i].col` optionnels (sélecteurs `input.cpk`) ; `fcol(i)` et `wlCol(um)` les lisent dans `App.sys`, sinon palette / couleur spectrale (`wlSpec`). Thème sombre par défaut (`focale.ui.th`).
- Surface 0 = objet, dernière = image ; champs {x, y} (angles si objet à l'infini — direction ∝ (tan x, tan y, 1) —, hauteurs sinon).
- Décentrements par surface (dx, dy, dz, tx, ty, tz en °, dmode DEC | DAR | BEN, rotations X→Y→Z main droite) : `frames()` calcule le repère de chaque surface, le tracé réel se fait en coordonnées globales et `trace()` renvoie le rayon dans le repère local de l'image. Le paraxial ignore décentrements et bascules.
- `sag(sf, x, y)` / `sGrad(sf, x, y)` : flèche et pente locales (partie de révolution + forme libre éventuelle).
- Avant chaque commit : `node tests/engine.test.js` doit passer, puis `python3 build.py`.
- Tolérancement (engine : `TOLT` types TFRN/TRAD/TIRR/TCON/TTHI/TIND/TABB/TSD*/TST*/TED*/TET*, `TOLC` critères WFE/SPOT/MTF (MTF : `up`, plus grand = meilleur, `tolWorse`)) :
  `tolBase` = solves figés + même compensation que les systèmes perturbés (`compensate` : variables V par `optStep` si `opts.vars`, puis `bestFocus` sur l'épaisseur avant l'image ; FTM → foyer au meilleur WFE).
  Liste : `cfg.list` (personnalisée, {type, j, min, max, on}) sinon `tolGen` depuis `cfg.types` ; `tolItems` filtre par `tolApplicable` et ajoute l'ouverture utile `h` (franges à `LT` = 632,8 nm).
  Application : décentrements DAR, `dn` (indice), `dv` (% sur νd, dispersion autour de nd dans `indices`), TFRN conversion exacte de flèche, TIRR → polynôme XY (ou Zernike) Δz = A(½ρ⁴ + ½ρy²).
  `tolSens`, `tolInverse` (modèle Δ ∝ t^p), `tolTrial`/`tolRebuild` (tirages, `rng` mulberry32 pour la graine, `tolDraw` normal/uniform/para/end), `niceDown`. UI : `openTol`, `renderTolL`, `renderTolRes`, `mcStats`, `mcContrib`, `tolLoad`.
- Verres : registre `glassRecord / addGlasses` (clé normalisée sans tirets ni espaces, suffixe `_CATALOGUE` pour lever les homonymies), formules refractiveindex.info `R2`/`R3` et Zemax AGF `A1`…`A13` dans `dispN`. `src/glasses.js` est généré : ne pas éditer à la main.
- Surfaces de forme libre : `type` = STD | XY (`xy` : {"i,j": c}) | ZERN (`zc`[16], rayon `zr`) ; intersection par Newton ; ignorées par le paraxial et les Seidel.
- Types d'éléments (`elem`) : '' (dioptre) | grating (`lpmm`, `gm`, `gang` ; réflexion si verre MIRROR) | ideal (`fid`, plan, puissance ajoutée au paraxial) | polarizer (`pang`) | waveplate (`ret` en ondes, `wang`). Traités dans `trace()` après l'intersection.
- Polarisation : `ray(..., { polState, fresnel })` propage un champ E complexe 3D (`polStep`) ; `polPupil` pour l'analyse. `imageSim` : cartographie des rayons principaux + PSF 5×5 dans le champ, objet à l'infini inversé (scène +v ↔ champ −y).
- Données système (CODE V) : fenêtre `openSysData(tab)` (onglets `SDT` / `SDTAB` : pup, wl, fld, env, mat, adv ; `sdChange` sur `data-sd`, `sdAction` sur `data-sda`, re-rendu par `renderSD()` depuis `refresh()`).
  Types de champ `sys.ftype` ∈ `OE.FTYPES` (ang YAN, obj YOB, pim YIM, rim YRI) ; `prepare` convertit vers l'interne (angles si objet à l'infini, hauteurs objet sinon ; angle en conjugué fini : h = −(t0 + zE)·tan θ ; pim/rim : valeur = coordonnée image, rim par Newton sur le rayon principal réel `realImageFields`) et garde `M.ufields`, `M.ftype`. `OE.convertFields(sys, to)`, `setFieldType(to, convert)` (app).
  Vignetage : `fields[i].vuy/vly/vux/vlx` (CODE V) → `vigMap` ; `ray()` remappe la pupille (sauf `{noVig}`) ou découpe (`{vigClip}`, utilisé par `wavefront`). `OE.setVignetting(sys)` = SET VIG (bisection sur les ouvertures 🔒). Zemax : VCY = (VUY+VLY)/2, VDY = (VLY−VUY)/2.
  Ouvertures : EPD, FNO, NA (objet), NAI (image), STOP (demi-diamètre du diaphragme). Apodisation `sys.apod = {type:'gauss', I}` (PUI) appliquée par `psf` (`sysApod`).
  Environnement `sys.env = {T, P (atm), Tref, expand, cteMount (10⁻⁶/K), mat: {clé verre: {D0…ltk, T0, cte}}}` ; `envCtx` (null au nominal), `envN` (Schott dn/dT absolu + air d'Edlén `nAir`, λ ramenée à l'air du catalogue), `expandLens` (CTE verre / entretoise `s.tce` / barillet), `indices(S, l, E)` ; `glassTherm(name, sys)` lit `src/glassth.js` (GÉNÉRÉ depuis refractiveindex.info : /tmp/gen/th.py, ne pas éditer à la main), les AGF (TD/ED) et les valeurs saisies. `thermalScan` → analyse `thermal`. Asphères A4…A20 (`OE.ASPK`, `sf.hi`).
- Fenêtres détachables : `App.fw[id]` (id side, lde, lay, p0…pN ; mémorisé dans focale.ui), `fwDetach`/`fwDock`/`fwClose`/`fwCreate`/`fwLayout` (grille #ws / #center recalculée selon les zones ancrées), `newFloatPane()` (+ Fenêtre), boutons `button[data-fw]` (⧉). Les panneaux sont trouvés par `.pane[data-i]` (grille #panes ou #floats).
- Import CODE V : qualificatifs `CMD Sk …`, listes indexées `WTW W2 2`, `SEQ_SILENT` (ignorées sans remarque), `SEQ_UNSUP` (une remarque explicite par famille). Test : `tests/codev_cmds.seq`.
- FTM : `otfAC` (autocorrélation directe de Hopkins, décalage fractionnaire, aucune interpolation en fréquence ; ≡ FFT aux décalages entiers, testé), `pupilScale` (ΔM, ΔL = écarts de cosinus directeurs des rayons de bord ±Y/±X dans le repère local de l'image × n′ : F/# réels T/S de CODE V ; donne fc = Δ/λ et le pas anisotrope `dxX`/`dxY` de `psf`/`psfGrid`), `mtf` (somme complexe pondérée des OTF déphasées par le rayon principal de chaque λ → chromatisme latéral), `mtfGeo` (FTM géométrique × limite de diffraction), `mtfAt` = `mtf` N 32. `mtfOne` (FFT) conservé pour les tests.
- Visée : `aimMode(sys)` = 'none' | 'chief' (sys.aimMode, rayon principal itéré au centre du diaphragme puis pupille paraxiale translatée : défaut CODE V, posé à l'import .seq) | 'full' (sys.rayAiming). Verre modèle `modelN(nd, vd, ΔPgF)` : 3 termes de Cauchy, Pg,F sur la ligne normale. CODE V PRE en mmHg (÷ 760).
- Zernike : `zernFit(wf, nz)` (Fringe Z1…Z37, `ZF` = [n, m, cos|sin], `ZN37`, `zRad`, RMS par terme `zRms`, résidu `R`/`rmsRes`/`pvRes`) ; analyse `zern` (`p.nz`, `ZNOPTS`), carte WFE `p.zres` (résidu). `zernBasis` (16 termes) reste utilisé par les surfaces Zernike et `wavefront`.
- Calculs en tâche de fond : `src/jobs.js` (`JOBS` : tâches async (args, prog) → résultat clonable ; mtf, tfmtf, mtffield, relillum, thermal, mcsum, tolBase, tolSens, tolInv, tolMC). Pool `BG` dans app.js : `runJob(nom, args, { group, key, want, onProg, onPart })`, workers créés depuis le texte des scripts `#js-glasses`, `#js-glassth`, `#js-engine`, `#js-jobs` (Blob), ping au démarrage, repli dans la page (`bgMain`) si les workers sont refusés ; `bgCancel(group)`, `bgStatus()` (#bgst). Analyses : `PT[type].job(p, M)` → `jobSpec` (clé = nom + options + `sysKey()`), `paneData` (cache `JCACHE`, `drawWait`), le rendu reçoit les données en 6ᵉ argument ; le rapport attend `runJob`. Tolérancement réparti en lots (`tolChunks`, `tolRun`), Monte-Carlo à tirages générés dans la page (`OE.tolTrialD`) : reproductible quel que soit le nombre de workers.
- Multi-configuration : `sys.mc = { n, cur, names, ops: [{ type, i, v[], vv[] }], opt: 'all'|'cur' }`, types `OE.MCT` (THI, RAD, CNC, GLA, SD, DX, DY, TX, TY, APE, FY, FX, WL, WW, TEM, PRE ; codes zmx/cv). Le système porte les valeurs de la configuration active ; `mcSync` (appelé par `refresh`) les recopie dans `v[cur]`, `mcSet`/`mcLoad`/`mcApply`. `residuals` additionne les configurations (opérande `op.cfg` = configuration 1…n), `getVars` : variables `{ mc, cfg }` pour les cellules V, paramètres pilotés exclus des variables de l'éditeur (`mcCtl`). `tolFreeze` retire `mc`. UI : `openMC`/`renderMC`/`mcEvent`/`mcAction` (attributs data-mc*), `#mcbar` (`renderMCBar`, `mcGo`), cellules LDE `.mcc`, analyse `mcsum`. IO : Zemax MNUM/MOFF/THIC… (`mcBuild`, `mcScale`, `zmap`), CODE V ZOO + qualificatif Zk (`zooAdd`).
- Analyses ajoutées : `OE.throughFocus` (FTM vs défocalisation, meilleur foyer), `OE.mtfField` (FTM vs champ, `fieldSweep` interpole le vignetage), `OE.relIllum` (`beamArea` : aire du faisceau dans l'espace des cosinus directeurs), `OE.distGrid`.
- Téléchargements : `download()` passe par la capacité `downloads` de claude.ai (`dlCap`, `claude.use('downloads')`) quand la page est dans un cadre ; extensions hors liste (.zmx, .seq, .agf) → « .txt » ajouté. La capacité est déclarée sur l'artifact (declare_capabilities).
- Surfaces : `type` TOR (biconique : `rx`, `kx`, variable `vrx` → kind `cx` ; `torSag`/`torGrad`, `polyZ`/`polyG` ; paraxial et Seidel sur la section Y) ; élément `doe` (`dm`, `dnr`, `da`[A1…A6], phase Σ Aᵢ ρ²ⁱ ; gradient de mλφ/2π ajouté dans `trace()`, puissance −mλA1/(πR²) dans `ptrace` via `n.lmm` posé par `indices`, variables `vdoe` → kinds `da0…`). IO : Zemax BICONIC/TOROIDAL/BINARY_2 (XDAT), CODE V CYL/XTO/YTO/RDX/CUX.
- Images fantômes : `OE.ghosts(M, {coat})` (paraxial, paires i<j, R Fresnel ou traitement, rel = R(r_signal/r_fantôme)²) ; analyse html `ghost`.
- Verres : `src/glassprop.js` GÉNÉRÉ (/tmp/gen/prop.py depuis refractiveindex.info : densité, ΔPgF, résistances, τ 10 mm aux λ `GLASSPROP_L`) ; `OE.glassProps`, `glassTau(name, λ, d)`, `sysTau` ; AGF : OD (prix relatif, résistances), IT (transmission), ED (densité). Fenêtre `openGlasses` : liste + diagramme interactif (`glassExt`, `GLW.view/col/ax/tl`).
- Optimisation v2 (merit.v = 2, `meritUpgrade` convertit les anciens fichiers : MNCT/MXCT/MNET/MXET → …G, CTHK/ETHK → CTGT/ETGT s1, poids au carré) :
  - `OPS[k]` = { g (groupe `OPG`), label, kind, u, cols ['s1','s2','w','hx','hy','px','py','p','fi'], pl/pdef, aka (noms Zemax / CODE V), list, math, nores, hide }. Noms Zemax pour les nouveaux (REAY, TRAY, RSCE, RWCE, CTGT, MNCG…, SUMM/DIFF/OPGT…), anciens noms Focale gardés (EFL, TTL, BFL…).
  - `opValue(M, op, rows)` : rows = valeurs des lignes précédentes (opérations, 1-based). Champ normalisé `fieldAt` (champ radial max), λ `wOf` (0 → primaire / poly), `rayRec` (trace avec `opts.rec` : x,y,z,L,M,N locaux, cos i, cos i′ par surface).
  - `residuals` → { f (√W·r), wt (Σ W), imgW, img2, cons (contraintes exactes `op.lag`), parts } ; mérite `meritOf(f, wt)` / `meritR(r)` = √(Σ W r² / Σ W) (Zemax). Critère image : `merit.image` SPOT|WFE|MTF|NONE, `ref` centroid|chief, `pupil` {type GQ|RA, rings, arms, grid} (`meritPupil`, `gaussLegendre`), `sym` (demi-pupille si `axisSym`), `iw` poids du critère, `mtfF`, `bnd` (contraintes de bord, lignes `auto:'bnd'`). WFE en ondes.
  - `optStep(state {sys, mu, central})` : DLS Marquardt + KKT pour les contraintes actives (al réduit si pas refusé), acceptation filtre (mérite / violation `consViol`).
  - UI : `openOptim` (DMF à gauche, éditeur MFE à droite), `opPicker`, `opDefaults`, `optWriteBounds`, `optSetVars`, `OPT.cyc`, `OPT.central`. Aide : rubriques `optimisation` et `operandes` (générée par `helpOps` depuis OE.OPS).
